# IELTS Atlas — 单词与工具版

基于 [sallowayma-git/IELTS-practice](https://github.com/sallowayma-git/IELTS-practice) v0.6.3.1 的个人词汇学习版本，保留原作者署名与 GPL-3.0 许可证。上游完整项目及其题库不在此重新发布。

本目录仅包含程序源码、运行文件、通用词表和工具。**不包含考试文章、题目、答案解析、PDF、听力音频或个人学习记录。**

## 使用

通过 GitHub Pages 打开本目录。首次进入直接显示背单词；更多工具包含时钟和词汇辅助功能。

- 点击“已掌握，不再出现”后，该词从后续任务排除。
- 一般／困难词每次提交后保存学习检查点；中途关闭不必重新从已处理的新词开始。
- 误标可通过右上角菜单 → 查看词表 → 恢复学习撤回。

学习进度保存在**当前浏览器、当前网站来源的 IndexedDB**，程序没有学习数据上传接口。同一设备换浏览器、清除站点数据或换网站地址会影响记录可见性。迁移时在旧页面导出进度，再在新页面本地导入；**不要把导出的进度或个人词表提交到仓库**。

## 源码与构建

本目录同时包含可编辑源码和生成的 `js/bundles/`，使用 Node.js 运行：

```sh
node scripts/build-bundles.mjs
node scripts/build-bundles.mjs --check
```

主要本地修改：逐词保存、手动掌握与恢复、异步切表隔离、词汇页刷新入口；此发行版另外移除题库清单和阅读入口，默认打开词汇页。不要直接手改生成 bundle。

通用词表保留在 `assets/wordlists/`，相关来源许可见同目录许可文件。第三方运行库保留文件内许可证；程序许可证见 [LICENSE](LICENSE)。
