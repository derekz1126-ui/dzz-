# DZZ / Fluid

Independent personal portfolio inspired by the visual language of neuv.fr. Original DZZ liquid typography, scroll-driven ink transition, experimental canvas art, project detail overlays and English/Chinese toggle. Desktop-first, buildless HTML/CSS/JavaScript.

Serve `dist/` with any static HTTP server. The previous DZZ Universe site is separate and unchanged. Only DZZ Universe is presented as a completed project; the other two entries are generative studies created for this website, not client work. Contact email supplied by the owner. No business data is included.

Font assets retain their open font licenses. GSAP and ScrollTrigger are local runtime libraries. No NEUV project artwork or proprietary code is included. Reduced-motion and WebGL fallback supported.
